Validated on 2026-08-30 with Python 3.12.13. This file distinguishes deterministic acceptance evidence from unavailable external-network evidence.

## Provider capability and source priority

The executable, complete matrix is generated by `provider_capability_matrix()` in `alpha_lab/providers/capabilities.py`; unspecified provider/field pairs are `UNSUPPORTED`.

| Provider | Reliable current | Reliable point-in-time | Partial | Deliberately unsupported |
|---|---|---|---|---|
| NASDAQ Trader | ticker, name, canonical exchange, active directory status | none | common-equity/security-type name fallback | prices, fundamentals, estimates, documents |
| yfinance | current OHLCV and adjusted close | market-dated prices only; current fundamentals have no filing knowledge time | current metadata, fundamentals, valuation inputs, dividends/buybacks where returned | historical fundamentals/estimate reconstruction |
| SEC Companyfacts | none (facts are filing observations) | mapped filed accounting facts with accession, filed date, period, form, unit and concept | issuer availability and concept coverage | EBITDA, FCF, ROIC, estimates, news, filing document text, issuer extensions |
| AlphaLab estimate snapshots | current snapshot at genuine observation time | prospective same-provider history | provider-supplied field availability | reconstructed history |

Field priority is domain-specific: NASDAQ Trader for canonical universe/exchange; yfinance for current OHLCV; SEC then yfinance per reported accounting field; yfinance then SEC only for fields the SEC mapping deliberately does not claim (for example EBITDA/FCF/shares); AlphaLab prospective observations for estimate history; stored attributable official documents for AI.

## SEC scope

Supported mappings: revenue, gross profit, operating income, net income, diluted EPS, cash, explicitly reported long-term debt and finance-lease obligations, equity, assets, current assets, current liabilities, dividends paid and common-stock repurchases. Facts preserve taxonomy, concept, unit, start/end, form, fiscal year/period, accession, frame, filed date, source URL and ingestion timestamp. Amendments append new knowledge versions.

Deliberately unsupported: speculative EBITDA/FCF/ROIC derivation, summing overlapping debt concepts, ambiguous issuer-extension concepts, incompatible/conflicting units, estimates, news and filing document text. Missing mappings remain unavailable.

## Remaining limitations and rejected shortcuts

Remaining unsupported domains include robust free historical analyst estimates, historical news, official filing document text ingestion, issuer-extension XBRL concepts, consistent ROIC, price/book, estimate dispersion for many issuers, and historical index membership. The current universe still carries survivorship-bias risk for historical studies.

Rejected approaches: treating current yfinance fundamentals as historical; inferring filing date from fiscal end; reconstructing revision history; averaging providers; summing overlapping SEC debt concepts; deriving EBITDA/FCF speculatively; treating share-count change as buyback value; scraping unofficial endpoints; and inventing a SEC contact identity. These would raise nominal coverage at the cost of correctness.
